**Notion Files Management v2.0.0-Beta 发布说明**

NFM 已从原 WPF/C# 桌面版迁移为基于 **FastAPI + Vue 3** 的本地 Web Console。启动后通过浏览器访问即可使用，也可以部署到服务器。

## 主要变化

- **Web 重构首发**：后端改为 FastAPI，前端改为 Vue 3 + Element Plus，统一通过 HTTP/SSE 通信。
- **全局任务看板**：集中查看扫描、上传、下载等长任务，支持取消、重试和下载产物入口。
- **云端缓存管理**：查看、下载、删除上传缓存、下载产物和临时 zip，并支持自动清理策略。
- **第三方开放 API**：新增 API Key 鉴权、scope 权限、过期时间、限流和短期 SSE token。
- **Windows 迁移包**：双击 exe 启动本机服务并自动打开浏览器，默认端口 `127.0.0.1:18765`。
- **安全加固**：修复 SSRF、上传会话路径越界、密码比较、输入边界、CORS 和 API Key URL 暴露面。

> 当前仍是 Beta 预发布阶段。建议先用小页面测试扫描、下载、上传流程，确认符合预期后再处理大批量任务。
